# Louis Adams — Portfolio

Local portfolio preview built with Astro, using writing from Ardent and the Poetry Events Platform project.

Run `npm install`, then `npm run dev`. Build with `npm run build`.

Project copy lives in `src/content/projects/poetry-events-platform.md`. Writing is in the other `src/content` folders. This preview has no publishing editor or subscriber email automation.

See [MEDIA.md](MEDIA.md) for adding videos, images, audio, and external embeds to projects or writing.
